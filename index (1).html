projects built end to end

Two builds worth explaining

PROJECT 01

Automated data validation & monitoring framework

  • Config-driven validation job in Databricks that compares source and target row counts, checks for duplicate and null primary keys, and flags column and datatype changes between loads.
  • Uses Delta Lake table history and time travel to reconcile each run against the previous version, writing run status, row counts and error detail into a central audit table.
  • Databricks alerts and ADF failure notifications, so a broken load is caught at run time instead of surfacing days later in a report.
DatabricksAzure Data Factory Delta LakePySparkSpark SQL
PROJECT 02

GDPR data erasure & PII anonymisation pipeline

  • ADF pipeline that picks up GDPR erasure requests and calls PL/SQL procedures to anonymise personal data across CRM staging and base tables.
  • Traced PII columns using column-level lineage and replaced values with masked substitutes, so foreign keys and downstream reports stay intact.
  • Logged every processed request as compliance evidence, stored database credentials in Azure Key Vault, and scheduled runs through ADF triggers.
